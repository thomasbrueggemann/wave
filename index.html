Sign in with Google

WAVE reads Drive straight from your browser, so it needs your permission to do that — read-only, and only while this tab is open. The access token is kept in memory and never stored; nothing is sent anywhere but Google.

Signing in lets WAVE open anything your account can already open — public “Anyone with the link” shares as well as folders shared with you directly.

Deployment setting — OAuth client ID

Set clientId in js/config.js and this section disappears for everyone. Until then, paste the client ID here and this browser will remember it. A client ID is public by design — there's no client secret in this flow.

  1. Open the Google Cloud console → Credentials and create (or pick) a project.
  2. Enable the Google Drive API.
  3. Configure the OAuth consent screen. While the app is unverified, add your own Google account under Test users.
  4. Create credentials → OAuth client ID → Web application. Add this page's origin under Authorized JavaScript origins.
