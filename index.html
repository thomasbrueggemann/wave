Drive API key

WAVE reads Drive straight from your browser. Google's share hosts don't allow that, so requests go to the Drive API instead — which identifies the app with a key. There's no sign-in and no account involved: the key only reads files already shared as “Anyone with the link”.

Set apiKey in js/config.js and this panel never appears for anyone. Until then, paste a key here and this browser will remember it.

  1. Open the Google Cloud console → Credentials and create (or pick) a project.
  2. Enable the Google Drive API for that project.
  3. Create credentials → API key. Restrict it to the Drive API, and add this page's origin under Website restrictions.

A browser key is meant to be public — it can't reach anything private in your Drive. Restrict it to your own origins so it can't be used to burn your quota elsewhere.
